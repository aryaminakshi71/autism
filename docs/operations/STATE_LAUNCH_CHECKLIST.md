# State Launch Checklist

Last updated: 2026-07-05

Use this checklist for each state separately: Washington, North Dakota, Connecticut, and Missouri. Do not assume approval in one state carries to another.

| --- | --- | --- | --- |

## Launch Decision

Launch is allowed only when all of these are true:

- The owner BCBA is licensed/authorized for the state.
- Medicaid or commercial payer effective date is confirmed.
- Prior authorization is obtained where required.
- Payroll, workers' comp, and employment setup are active.
- RBT supervision capacity is available and documented.
- HIPAA/BAA controls are in place for every vendor and offshore staff role.
- A claim can be submitted, tracked, followed up, and reconciled without manual guessing.

If any item is blocked, classify the state as `blocked` in the Operations dashboard.
