# State Medicaid Requirements Watchlist

Last updated: 2026-07-05

This is a working compliance watchlist for Washington, North Dakota, Connecticut, and Missouri. It is not a substitute for the current state Medicaid manual, payer contract, authorization letter, or legal review. Before any client is scheduled or billed, verify the current provider manual, CPT/modifier rules, authorization requirements, effective dates, and documentation rules for that exact payer.

## Practical Launch Rule

For each client, create a payer folder with:

- Eligibility screenshot or verification record.
- Authorization letter with dates, CPT codes, modifiers, units, setting, and provider.
- Current treatment plan and signature.
- Rendering provider credential/license confirmation.
- RBT supervision assignment and BCBA supervision formula.
- Session note template matched to payer requirements.
- Claim template with authorization number and place of service.
- Follow-up log for every unpaid or denied claim.

## BCBA Capacity Impact

State Medicaid rules directly reduce the number of clients one BCBA can manage. A 40-hour BCBA week can support more clients only when:

- Authorization packets are clean before treatment starts.
- RBT notes are complete within the payer/state deadline.
- RCM staff prevent claim aging and denials.
- Supervision logs meet BACB, state, and payer rules.
- Reauthorization work is started before units run low.
- High-risk clinical events are reviewed the same day.

If any state has unpaid claims over 45 days, repeated documentation defects, or incomplete RBT supervision records, pause growth in that state before adding new clients.

## Important Clarification

Direct therapy hours/client/week are not the same as BCBA hours/client/week.

- Direct therapy hours are usually delivered by an RBT/technician under the treatment plan and supervision.
- BCBA/LBAT/LBA hours are supervision, protocol modification, assessment, treatment planning, caregiver training, and clinical oversight.
- A common practical model is about 2-3 BCBA hours/client/week for a 20-25 hour/week direct therapy program, but the exact number must follow the authorization, treatment plan, state rule, payer rule, and clinical need.
