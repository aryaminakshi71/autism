# Insurance Claim Follow-Up Call Scripts

Last updated: 2026-07-05

Use these scripts for India RCM staff. Do not disclose more PHI than needed.

## Before Calling

Have this ready:

- Provider name and NPI.
- Tax ID if allowed by policy.
- Payer portal claim ID.
- Patient name or payer-approved identifier.
- Member ID.
- Date of service.
- CPT/modifier/units.
- Billed amount.
- Authorization number.
- Clearinghouse trace number.

## Basic Claim Status Script

Hello, my name is [NAME]. I am calling on behalf of [PROVIDER/ORGANIZATION]. I am checking claim status for a behavioral health/ABA claim.

Provider NPI: [NPI]  
Member ID: [MEMBER ID]  
Date of service: [DOS]  
Claim number or trace number: [CLAIM/TRACE]  

Can you please confirm:

1. Was the claim received?
2. What is the current status?
3. Is anything needed from the provider?
4. Is there a denial or pending reason code?
5. What is the expected processing date?
6. What is the call reference number?

## No Claim Found Script

Can you search by date of service, member ID, billed amount, provider NPI, and clearinghouse trace number?

If still not found:

1. Confirm correct payer address or electronic payer ID.
2. Confirm whether the claim should be submitted to another payer or MCO.
3. Ask whether resubmission is allowed.
4. Ask whether the resubmission should be marked original or corrected.
5. Record the reference number.

## Denial Script

Can you read the denial reason and code exactly as shown?

Please confirm:

1. Is this appealable or should it be corrected and resubmitted?
2. What documents are required?
3. What is the appeal deadline?
4. Where should the appeal/correction be sent?
5. Can this be handled through the portal?
6. What reference number should we use?

Do not argue clinical necessity. If denial involves medical necessity or documentation, escalate to Owner BCBA.

## Underpayment Script

We expected payment based on the contracted or published rate. Can you confirm:

1. Allowed amount.
2. Paid amount.
3. Patient responsibility.
4. Contracted rate used.
5. Any bundling, modifier, or multiple procedure reduction.
6. Whether reconsideration is available.

## Documentation Request Script

Please confirm the exact documents requested and deadline.

Do not send documents during the call unless the approved workflow allows it. Escalate to Owner BCBA or BCBA B before sending clinical records.

## Call Close

Thank you. Can you repeat the reference number and next step?

I have:

- Status: [STATUS]
- Next action: [ACTION]
- Deadline/follow-up date: [DATE]
- Reference number: [REF]

Thank you for your help.
