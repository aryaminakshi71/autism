# Autism Center Operations Document Packet

Last updated: 2026-07-05

This folder contains working documents for a staged autism center launch across Washington, North Dakota, Connecticut, and Missouri with one primary BCBA, delegated India-based software/RCM support, and AI-assisted video monitoring.

These documents are operating templates. They are not legal, tax, clinical, or payer-contract advice. Final versions should be reviewed by a healthcare attorney, CPA, credentialing specialist, and the supervising BCBA before use with real PHI, payer submissions, or staff.

## Documents

| Document | Purpose |
| --- | --- |
| `STATE_LAUNCH_CHECKLIST.md` | State-by-state gate checklist before accepting/scheduling a client. |
| `BCBA_LEARNER_AND_APP_READINESS_MEMO.md` | Answers whether learner BCBAs help capacity and whether the app is ready for multi-BCBA/RBT/state use. |
| `HIPAA_COMPLIANCE_OPERATING_PLAN.md` | Practical HIPAA operating plan for software, video, billing, and offshore access. |
| `BUSINESS_ASSOCIATE_AND_OFFSHORE_VENDOR_CHECKLIST.md` | BAA and India vendor/subcontractor control checklist. |
| `INDIA_RCM_CLAIMS_OPERATIONS_SOP.md` | India billing/claims workflow, roles, queues, and escalation rules. |
| `INSURANCE_CALL_SCRIPTS.md` | Scripts and logs for calling insurance companies about unpaid claims. |
| `PAYER_LIBRARY_AND_CLAIMS_TEMPLATES.md` | State payer starter library and reusable enrollment/auth/claim/follow-up templates. |
| `AUTOMATED_CLAIMS_AND_CALL_CENTER_WORKFLOW.md` | Claim-readiness automation, separate RBT/BCBA claim lines, state/payer rate rules, and India call-center queues. |
| `STATE_MEDICAID_REQUIREMENTS_WATCHLIST.md` | State Medicaid ABA requirements to verify before scheduling or billing in WA, ND, CT, and MO. |
| `AI_VIDEO_MONITORING_SAFETY_SOP.md` | AI-assisted video alert process for RBT supervision and child safety escalation. |
| `BCBA_CAPACITY_AND_DELEGATION_MODEL.md` | Practical caseload limits and delegation model for one BCBA across four states. |
| `HIGH_HOUR_RETENTION_AND_DUAL_BILLING_MODEL.md` | High-authorized-hour intake strategy, RBT retention model, and separate RBT/BCBA billing tracks. |
| `FINANCE_ENTITY_AND_PNL_MODEL.md` | Entity choice, India contractor/company decision, cost model, and 10-15 client P&L. |
| `REVENUE_REALITY_MISSED_VISITS_AND_DENIALS.md` | Revenue sensitivity, missed visit loss, denial loss, and BCBA owner earnings. |
| `PRODUCT_GAP_ROADMAP.md` | Remaining software gaps and staged build roadmap. |

## Immediate Use

1. Use `STATE_LAUNCH_CHECKLIST.md` before starting each state.
2. Use `BCBA_LEARNER_AND_APP_READINESS_MEMO.md` before hiring trainees, BCaBAs, or additional supervisors.
3. Use `HIPAA_COMPLIANCE_OPERATING_PLAN.md` and `BUSINESS_ASSOCIATE_AND_OFFSHORE_VENDOR_CHECKLIST.md` before giving India staff access to any PHI.
4. Use `INDIA_RCM_CLAIMS_OPERATIONS_SOP.md` and `INSURANCE_CALL_SCRIPTS.md` once claims are submitted.
5. Use `AUTOMATED_CLAIMS_AND_CALL_CENTER_WORKFLOW.md` before releasing claims or assigning India call-center tasks.
6. Use `STATE_MEDICAID_REQUIREMENTS_WATCHLIST.md` before assuming any Medicaid service is authorized or billable.
7. Use `AI_VIDEO_MONITORING_SAFETY_SOP.md` before enabling video monitoring or AI alerts.
8. Use `HIGH_HOUR_RETENTION_AND_DUAL_BILLING_MODEL.md` before accepting low-hour cases or staffing RBTs.
9. Use `FINANCE_ENTITY_AND_PNL_MODEL.md` before hiring, opening a new state, or committing to India company setup.
10. Review `PRODUCT_GAP_ROADMAP.md` before building deeper claims, payroll, and AI integrations.
